Test-ILA · Convertisseur Lesen

Importe le fichier lesen-import-brut.js, vérifie le texte de chaque PDF et génère directement un Modelltest HTML téléchargeable et utilisable.

À savoir : ce convertisseur organise le contenu, mais ne peut pas deviner de façon fiable toutes les questions, les bonnes réponses ou la structure des tableaux/graphiques. Vérifie les champs avant d'intégrer le résultat à lesen-data.js. Ton fichier original n'est jamais modifié.

1. Charger le fichier extrait

Le fichier doit contenir une déclaration de la forme window.LESEN_IMPORT = [...], comme l'export de ton importateur PDF.

Aucun fichier chargé.

2. Organiser les 7 Aufgaben

Choisis le type correspondant au contenu réel de chaque PDF. Le convertisseur propose un type détecté automatiquement, mais tu peux le corriger.

3. Créer le Modelltest

Le fichier téléchargé sera une page HTML autonome avec les 7 Aufgaben, le texte extrait de chaque PDF, des zones de réponse et un chronomètre. Il sera utilisable directement, sans modifier lesen-data.js.

4. Résultat

Le fichier HTML sera téléchargé automatiquement. Tu peux ensuite l’ouvrir dans ton navigateur ou l’intégrer à ton site.
